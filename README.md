# 给酉雪云的生日小旅程

这是给酉雪云准备的生日互动礼物，当前版本已经加入她的生日信息与用户提供的图片素材：

- 酉雪云 / 21 岁 / 10 月 16 日 / 天秤座
- 用户提供的淡蓝色蝴蝶：`assets/butterfly-user.png`
- 用户提供的生日蛋糕前照片：`assets/youxueyun-wish.jpg`

## 页面流程

1. 开场：今天的主角，生日快乐
2. 第一站：公主，请许愿；蜡烛前有循环流星，熄灭后出现愿望成真的祝福
3. 第二站：吃点好的；点击三个吃货卡片查看提示
4. 第三站：生日当天任务清单
5. 第四站：真正的 8 数码滑块拼图；点击相邻拼图移动，旁边的“笨笨哒 🦋”按钮可以选择继续思考或直接通关
6. 第五站：点击气球收集生日祝福
7. 结尾：祝福已送达

所有页面都是固定全屏场景，不使用上下滚动。页面切换时，上一页会渐隐、模糊并由粒子消散，背景中的蝴蝶会闪烁飞散，下一页再渐变出现。

## 打开方式

直接双击 `index.html` 即可打开。

如果浏览器对本地文件的资源加载不完整，可以在项目目录启动：

```bash
python -m http.server 5173
```

然后访问 `http://localhost:5173/`。

## 可继续替换的内容

吃货区域目前使用插画式食物卡片，不依赖额外网络图片。之后如果想加入食物照片，可以把图片放进 `assets/`，再替换对应的 `.food-card` 内容。
